# BarkTalk (바크톡) · 음성 MVP

강아지 짖음 소리를 녹음하거나 파일로 올리면 기분을 추정해 주는 무료 웹앱(PWA)입니다. 빌드 과정 없이 이 폴더를 그대로 올리면 됩니다.

## 무료로 공개하는 방법

- **GitHub Pages:** 이 폴더 내용을 저장소에 올리고 Settings → Pages에서 배포 브랜치를 고르면 `https://<아이디>.github.io/<저장소>/` 주소가 생깁니다.
- **Cloudflare Pages:** 저장소를 연결하고 빌드 명령은 비워 두면 됩니다.
- 녹음(마이크)은 https 주소에서만 동작합니다. 위 두 곳 모두 https를 무료로 줍니다.
- 휴대폰에서 주소를 연 뒤 "홈 화면에 추가"를 누르면 앱처럼 설치됩니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| index.html, style.css | 화면 (첫 화면 → 업로드 → 분석 중 → 결과) |
| app.js | 녹음, 파일 업로드, 상황 선택, 결과 표시, 피드백·기록(기기에만 저장) |
| analyzer.js | 분석: YAMNet 소리 분류 + 음높이·짖는 횟수·간격 계산 + 규칙표 |
| sw.js, manifest.webmanifest, icon* | 홈 화면 설치와 오프라인 사용 |

## 분석 방식과 한계

- 소리는 서버로 보내지 않고 브라우저 안에서만 분석합니다.
- YAMNet(구글 공개 모델)을 처음 한 번 인터넷에서 받아 저장합니다. 못 받으면 소리 특징만으로 분석하고, 결과의 "들린 소리"에 그 사실을 표시합니다.
- 1순위 확신도는 과신을 막으려고 30~85% 사이로 제한합니다.
- 결과는 참고용 추정입니다. 규칙표 값은 첫 버전의 출발점이며, 피드백("맞았어요/틀렸어요")이 쌓이면 조정해야 합니다.
